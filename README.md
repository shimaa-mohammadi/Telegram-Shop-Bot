# 🤖 ربات فروشگاه (Roozhano Shop Bot)

ربات فروش تلگرامی با رابط کاربری مدرن (دکمه‌های اینلاین + ایموجی) برای فروش، تمدید و مدیریت سرویس‌ها.

ساخته‌شده با **aiogram 3** (جدیدترین فریمورک پایتون برای تلگرام) + دیتابیس **SQLite** (بدون نیاز به نصب چیز اضافه).

---

## ✅ امکانات

### بخش مشتری
| دکمه | توضیح |
|---|---|
| 🔒 عضویت اجباری | تا کاربر عضو کانال نشود، هیچ بخشی باز نمی‌شود (دکمه عضویت + بررسی عضویت) |
| 🧪 اکانت تست | همان فلوی خرید؛ اگر قیمت تست در کانفیگ ۰ باشد، پرداخت ندارد و مستقیم برای تایید مدیر می‌رود |
| 🛒 خرید سرویس | اسم دلخواه ← انتخاب سرویس ← نمایش شماره کارت ← ارسال رسید ← تایید مدیر |
| 🔄 تمدید سرویس | انتخاب از سرویس‌های فعال خود کاربر ← پرداخت ← تایید مدیر |
| 📂 سرویس‌های من | لیست سرویس‌های تایید‌شده + اطلاعات/کانفیگ هر سرویس |
| 💰 اعتبار من | کیف پول؛ شارژ با رسید ← تایید مدیر؛ امکان پرداخت سفارش از اعتبار |
| 🏷 تعرفه‌ها | نمایش قیمت و مدت همه سرویس‌ها |
| 📚 آموزش استفاده | متن آموزش (از کانفیگ) + لینک سایت |
| ☎️ پشتیبانی | لینک چت پشتیبانی، تماس تلفنی و ارسال پیام مستقیم (مدیر می‌تواند پاسخ دهد) |

### جریان خرید (دقیقاً طبق خواسته شما)
```
🛒 خرید سرویس → ۱) اسم دلخواه → ۲) انتخاب سرویس → ۳) شماره کارت + ارسال رسید → ۴) تایید مدیر ✅
```
- وقتی مدیر «✅ تایید» می‌زند، ربات از مدیر می‌پرسد اطلاعات سرویس را بفرستد → همان محتوا مستقیم برای مشتری ارسال و در «سرویس‌های من» او ثبت می‌شود.
- رد سفارش با یا بدون دلیل + برگرداندن خودکار اعتبار (اگر با کیف پول پرداخت شده بود).
- کارت سفارش برای همه مدیران تعریف‌شده در `ADMINS` ارسال می‌شود.

### پنل مدیریت (دستور `/panel`)
- 📊 آمار ربات: کاربران، سفارش‌ها، درآمد تاییدشده
- ⏳ سفارش‌های در انتظار: تایید / رد (با یا بدون دلیل)
- ➕ شارژ اعتبار کاربر (عدد منفی = کسر)
- 📢 ارسال پیام همگانی به همه کاربران (متن، عکس، ویدیو)
- ↩️ پاسخ به پیام‌های پشتیبانی

## 🚀 راه‌اندازی (روی کامپیوتر خودتان)

### ۱. نصب پیش‌نیازها
فایل **`install.bat`** را دابل‌کلیک کنید (یا در cmd):
```
python -m pip install -r requirements.txt
```

### ۲. تنظیم `config.json`
> 🔐 فایل `config.json` (به‌دلیل داشتن توکن و اطلاعات شخصی) در گیت ذخیره نمی‌شود؛ فایل **`config.example.json`** را با نام `config.json` کپی کنید و مقادیر را پر کنید.

| فیلد | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMINS` | آیدی عددی خودتان — بعد از اولین اجرا، در ربات `/id` بزنید |
| `CHANNELS` | کانال‌های اجباری، مثل `"@mychannel"` — **ربات باید ادمین کانال باشد** تا عضویت چک شود. برای تست بدون کانال: `[]` |
| `BRAND_NAME` | نام فروشگاه |
| `SITE_URL` | لینک سایت |
| `SUPPORT_USERNAME` | آیدی پشتیبانی (بدون @) |
| `PHONE` | شماره تماس پشتیبانی |
| `CARD` | بانک، شماره کارت، نام صاحب کارت |
| `SERVICES` | سرویس‌ها: `id`، `title`، `volume`، `duration`، `price` (تومان) |
| `TEST_SERVICES` | اکانت تست‌ها؛ اگر `price: 0` باشد پرداخت ندارد |
| `LIMIT_TESTS` | `true` = هر کاربر فقط یک اکانت تست |
| `TUTORIAL_TEXT` / `TUTORIAL_URL` | متن و لینک آموزش |
| `WELCOME_TEXT` | متن صفحه اصلی (خالی = پیش‌فرض) |
| `LOGO_PATH` | عکس لوگو، مثل `"logo.jpg"` کنار ربات (اختیاری) |

### ۳. اجرا
فایل **`run.bat`** را دابل‌کلیک کنید (یا `python bot.py`).

نکته: اگر ربات آفلاین بود (کامپیوتر خاموش)، پیام‌ها با `drop_pending_updates` حذف می‌شوند تا سرریز نشوند.

## 💡 نکات مهم

1. **بررسی عضویت:** ربات حتماً باید ادمین کانال باشد؛ وگرنه بررسی به‌صورت خودکار نادیده گرفته می‌شود (ربات قفل نمی‌شود).
2. **کانال خصوصی:** به‌جای `@username` این شکل را بگذارید:
   ```json
   "CHANNELS": [{"id": "-1001234567890", "url": "https://t.me/+AbCdEf..."}]
   ```
3. **دیتابیس:** فایل `shop.db` کنار ربات ساخته می‌شود — کاربران، سفارش‌ها و اعتبارها همه آنجا ذخیره می‌شوند.
4. **پرداخت از اعتبار:** اگر موجودی کاربر کافی باشد، دکمه «💰 پرداخت از اعتبار» هم در صفحه پرداخت ظاهر می‌شود؛ در صورت رد سفارش، مبلغ خودکار برمی‌گردد.
5. **اکانت تست پرداخت‌دار:** اگر می‌خواهید اکانت تست هم مثل خرید شماره کارت و رسید داشته باشد، `price` آن را در `TEST_SERVICES` بزرگ‌تر از صفر بگذارید.
6. چند مدیر؟ کافی است چند آیدی در `ADMINS` بگذارید؛ کارت همه سفارش‌ها برای همه ارسال می‌شود و اولین تایید/رد نهایی است.

## 🧪 چک‌لیست تست سریع

1. توکن را در `config.json` بگذارید + آیدی خودتان در `ADMINS`
2. `run.bat` را اجرا کنید → پیام «✅ ربات راه‌اندازی شد» ببینید
3. در تلگرام `/start` بزنید → صفحه عضویت کانال (اگر کانال تنظیم شده)
4. بعد از عضویت → منوی اصلی با ۸ دکمه
5. 🛒 خرید سرویس → اسم → سرویس → کارت → ارسال رسید
6. `/panel` → سفارش در انتظار → ✅ تایید → ارسال اطلاعات سرویس
7. 📂 سرویس‌های من → سرویس تاییدشده با اطلاعات
